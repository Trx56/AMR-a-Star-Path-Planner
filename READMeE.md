# 3D AMR Labyrinth Path Planning Simulation

A 3D simulation of an Autonomous Mobile Robot (AMR) navigating a multi-corridor labyrinth environment. Built for robotics and automation engineering applications.

## Features
- **A* Pathfinding Algorithm:** Computes optimal, collision-free trajectories across an 8-directional grid matrix.
- **3D Spatial Visualization:** Extrudes grid cells into 3D warehouse walls using Matplotlib.
- **Dynamic Trail Generation:** Renders real-time breadcrumb tracking as the robot moves toward its final goal.

## Tech Stack
- Python
- NumPy
- Matplotlib
